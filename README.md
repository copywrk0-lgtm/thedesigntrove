# The Design Trove — Independent Website Concept

Next.js static export, GSAP ScrollTrigger, and Lenis.

## Run locally

1. Install Node.js 20.9 or later.
2. Open a terminal in the extracted project folder.
3. Run `npm ci`.
4. Run `npm run dev` and open http://localhost:4173.

## Build and deploy

Run `npm run build`. The `out` folder is the static website output and can be hosted by a static hosting provider. Vercel can build this source project using its Next.js preset.

The included `static-export` folder is a ready-built copy of the latest version. Serve it using a local HTTP server rather than opening the HTML files directly.

## Included features

- Photo crossfade hero and responsive typography.
- Three desktop sticky chapters and scroll-driven image zooms.
- Pinned horizontal galleries on desktop; swipe galleries on touch devices.
- Clip-path photo reveals and reduced-motion fallbacks.
- 1.8-second wordmark and curtain intro, once per browser session.
- Homepage and residence study page.
